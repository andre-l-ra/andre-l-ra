### 👨‍💻 Sobre

Desenvolvedor backend com experiência prática em **sistemas corporativos, automação comercial e
domínio fiscal/tributário brasileiro** — documentos fiscais (NF-e/NFC-e), regras de negócio de ERP,
suporte técnico especializado e consultoria a clientes e contadores.

Meu foco é transformar **regras de negócio complexas e reais** em software bem arquitetado,
testável e escalável, aplicando Clean Architecture, DDD e SOLID como ferramenta para resolver
problemas de quem usa o sistema todos os dias — não como teoria.

- 🏢 Atuação: automação comercial + sistemas fiscais e tributários
- 🎯 Buscando: posições de Engenheiro de Software Backend / .NET (inclusive remoto internacional)
- 🌐 Itapipoca-CE, Brasil
